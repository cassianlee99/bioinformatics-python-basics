\# Bioinformatics Python Basics



This mini-project demonstrates basic data handling and visualisation in Python for bioinformatics-style analysis.



\## Files

\- \*\*gene\_expression\_data.csv\*\* — sample dataset with gene names and expression levels  

\- \*\*gene\_expression\_summary.py\*\* — Python script that reads the CSV, calculates summary stats, and plots expression levels  

\- \*\*gene\_expression\_plot.png\*\* — generated output plot



\## Skills Demonstrated

\- Python (pandas, matplotlib)

\- Data analysis

\- Basic bioinformatics concepts (gene expression)

\- Git version control
